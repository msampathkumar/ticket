# Security Policy

## Supported Versions

We actively maintain and provide security updates for the following versions of `tk`:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

The `tk` team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

### Disclosure Process
1. **Do not open a public GitHub issue** for suspected security vulnerabilities.
2. Report vulnerabilities by opening a private GitHub Security Advisory at:
   - [https://github.com/msampathkumar/ticket/security/advisories/new](https://github.com/msampathkumar/ticket/security/advisories/new)
3. Please include:
   - Detailed description of the vulnerability
   - Steps to reproduce or proof-of-concept script
   - Affected CLI commands, REST endpoints, or dependencies
   - Potential impact

### Response Time
- **Acknowledgment**: Within 48 hours of initial report.
- **Triage & Status**: Within 5 business days with an assessment and remediation plan.
- **Release**: Fixes will be published in a patch release and documented in the release notes.
